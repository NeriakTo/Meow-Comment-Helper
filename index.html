☁️ 貓貓雲端同步

▶ 還沒有雲端貓窩？教我怎麼蓋一個！🛠️

📋 Step 1：複製程式碼

請先複製以下這段程式碼：

// ⚠️ 請將下方 "meow1234" 改為自訂密語！
var SECRET = "meow1234";

function doPost(e) {
  var payload = JSON.parse(e.postData.contents);
  // 驗證通關密語
  if (payload.secret !== SECRET) {
    return ContentService.createTextOutput(JSON.stringify({"result":"error","message":"密語錯誤"})).setMimeType(ContentService.MimeType.JSON);
  }
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.getRange("A1").setValue(JSON.stringify(payload.data));
  return ContentService.createTextOutput(JSON.stringify({"result":"success"})).setMimeType(ContentService.MimeType.JSON);
}
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getRange("A1").getValue();
  return ContentService.createTextOutput(data).setMimeType(ContentService.MimeType.JSON);
}

🆕 Step 2：建立專案

點擊 這裡前往 Google Apps Script，點選『新專案』，並將剛剛複製的代碼 覆蓋 掉原本的內容。

🚀 Step 3：部署為網頁應用程式

點擊右上角 『部署』(Deploy) → 『新增部署』：

  1. 類型選擇：網頁應用程式 (Web App)
  2. 誰可以存取：務必選 『所有人 (Anyone)』 (很重要！)
  3. 點擊 『部署』

🔗 Step 4：取得網址

複製部署完成後的 『網頁應用程式網址』（以 exec 結尾），並貼到下方的輸入框中。
